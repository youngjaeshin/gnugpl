# GNU Geophysics Lab website

Read docs/SESSION_HANDOFF.md for the user-approved final state, then README.md for the maintenance workflow. This file replaces the obsolete March 2026 instructions.

## Architecture

Six static public HTML pages, generated by Python standard-library scripts. No application server or database. Tailwind 3.4.19 is compiled to local CSS; never reintroduce the Play CDN runtime.

- Edit `templates/pages/*.html`, not root generated HTML.
- Common navigation/footer: `templates/partials/`.
- Papers: `papers/metadata.json`. Thirteen verified published papers as of 2026-09-11.
- Profile: `data/profile.json` holds verified education, all career entries and the photograph. `data/site.json` holds current site-level rank/contact information; the build checks date/rank consistency. User confirmed promotion to Associate Professor in September 2026 and one current member.
- News: `data/news.json`; reference papers by DOI.
- Research: `data/research.json`; exactly three user-defined fields: 탄성파 자료처리 및 영상화, 지구과학 머신러닝, 응용지구물리탐사. Do not turn individual papers (e.g. CCS monitoring) into standalone research fields.
- Photos: `data/gallery.json`; an empty array produces an honest empty state.
- Source provenance: `raw/manifest.json` and `data/assets.json`.
- Existing manuscripts and the dated presentation bundle live under `raw/`; keep them out of deployment output.

## Commands

```sh
npm ci
npm run build
npm run check
npm run check:sources  # Local checkout with raw PDFs
npm run preview
```

Preview serves `dist/` at port 8765. PDF verification requires Poppler (`pdftotext`). `npm run build` generates root HTML, compiles CSS and packages only the public allowlist into `dist/` (no PDFs).

## Content rules

- Verify bibliographic metadata from source PDFs. Distinguish online dates from issue years.
- Never invent biographies, students, academic achievements, photo captions or paper abstracts.
- The CV confirms initial GNU appointment in September 2022. Bachelor: SNU Energy Resources Engineering 2008.03–2014.02; doctorate: SNU Energy Systems Engineering 2014.03–2019.08.
- In Members, show only a concise 주요 연구 summary; emphasize education and career.
- CV originals under `raw/profile/` are Git-ignored and excluded from deployment. Never copy personal identifiers or residential contact details into public profile data.
- A separate research-project tab is deferred by explicit user instruction.
- GNU source files are read-only references. The local working copy has all 13 source PDFs under `raw/publications/`; raw bundles, PDF copies and workshop recordings are excluded from Git.
- Changes must preserve source hashes or explicitly update the source manifest when a new original is supplied.
- Raw-folder placement does not make files private in a public Git repository.
