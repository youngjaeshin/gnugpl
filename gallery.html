사진 추가 방법

1. 이미지 파일 준비

JPG 또는 WebP 형식, 권장 크기: 1200×800px 이상, 4:3 비율. 파일명: gallery-01.jpg ~ gallery-12.jpg

2. images/ 폴더에 업로드

gnugpl/images/ 폴더에 파일을 복사합니다. GitHub Pages에 push하면 자동으로 반영됩니다.

3. gallery.html 수정

각 .gallery-item의 플레이스홀더 div를 <img> 태그로 교체하세요.
