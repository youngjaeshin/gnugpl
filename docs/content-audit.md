## 홈페이지 정리

- 원본으로 뒷받침되지 않는 과거 논문 게재/학회 소식을 검증된 최근 논문과 승진 소식으로 교체.
- TT 파동장 분리 논문의 잘못된 Geophysics 저널 표기를 Applied Sciences로 정정.
- 연구 분야의 가상 그림, 경로 안내, 근거가 없는 세부 성과 주장을 실제 게재 논문에 연결한 설명으로 교체.
- SCI(E) 전체 분류는 개별 저널의 등재 상태를 별도로 확인하지 않았으므로 일반적인 '저널 논문'으로 변경.
- 종료 예정일이 지난 과제의 '3차년도 진행중' 표기를 제거. 별도 연구과제 탭은 만들지 않음.
- 학생 자리표시자와 공개 페이지의 사진 업로드 설명을 제거. 교수 1명과 실제 갤러리 빈 상태를 명확하게 표시.
- 확인되지 않은 대학 규모 수치, 버스 번호·소요시간, 박사학위논문 제목을 제거. 방문자는 현재 지도 경로와 이메일로 확인할 수 있음.
- 연락처의 빈 아이콘 줄 제거, 직급·이메일·메뉴·푸터를 공통 데이터와 템플릿으로 생성.

## 구현 개선

- [Tailwind 공식 CLI 설치 방식](https://v3.tailwindcss.com/docs/installation)에 따라 CSS를 사전 생성. CDN 스크립트와 런타임 설정 제거.
- 모바일 메뉴 resize/Escape/외부 클릭 처리. JavaScript가 없어도 메뉴와 본문을 읽을 수 있게 함.
- 논문 연도 필터, 선택 상태, 결과 편수 접근성 처리. 갤러리는 실제 사진에만 native dialog 연결.
- 숨겨진 사진의 빈 src 요청, 기본 투명 reveal, 숨은 맨 위로 버튼의 키보드 포커스 문제 해결.
- 발표 원본/원고/설명 이미지를 raw에 보관하고, 공개용 빌드는 참조된 홈페이지 파일과 게재 논문만 포함.

## 학력 표기 통일

학력의 기관 표시는 두 항목 모두 '서울대학교'로 통일하고 학과와 학위로 구분한다. 사용자 확인에 따라 메타데이터도 institution=서울대학교, college=공과대학으로 통일하고 program_level로 학부/대학원을 구분한다. 이력서의 원래 기관 표기(서울대학교 대학원/서울대학교 공과대학)는 source_institution에만 출처 이력으로 유지한다. 서울대학교 공식 [대학원 에너지시스템공학부 안내](https://eng.snu.ac.kr/academics/graduate-programs/energy-systems-engineering)와 [학부 에너지자원공학과 안내](https://eng.snu.ac.kr/academics/undergraduate-programs/energy-resources-engineering)를 확인했다.
